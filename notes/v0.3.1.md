### Added

- Wiki folders for owners and admins only. A restricted folder and everything inside it leave the library, the search and the export for the other members, and for API tokens and AI agents below the admin role.
- Wiki folders that ask for a password. The right password opens the folder for 30 minutes in that session, **Lock now** closes it sooner, and five wrong tries in a row make the person wait. Only a signed in browser unlocks a folder: API tokens and AI agents never open one. An owner of the workspace or Orbit's administrator removes a forgotten password, and that is recorded in the activity. A password is a lock on the door, not encryption: the text is stored like any other page and is part of the backups.
- One search for the wiki, on Command+K, Ctrl+K or `/`. It marks the match, moves with the arrow keys and offers to create a page or a folder with the words typed when nothing matches.
- Wiki pages have a **Copy** button on code blocks, contents that follow the section being read, and the previous and the next page of their folder at the end.

### Changed

- The wiki has a new screen. With no page open, a collection is a night sky where its folders are planets, the people who wrote there show as a crew and Ted says a line that changes with the day. Every page and folder has a cover drawn from its own id in the colors of the theme, the editor takes the whole width with the page beside the text, and up to three pages with no edit in over two months are listed so someone checks whether they still hold.
- More room to read in the wiki. Orbit's sidebar steps aside and **Menu** brings it back, and the library folds away. On a 1440 pixel screen the text went from about 500 to about 800 pixels wide.
- An address written as plain text in a wiki page is a link.
- A Space is measured by the counters Garage keeps. Its size and its number of files, in the charts and on its page, are what its buckets hold. The size used to be the volume on the disk, which also had Garage's own index.
- A database that cannot be measured is asked again after 1 minute, then 2, 4, 8 and from there every 15, instead of twice a minute. When the wait gets there, Orbit's log has a `database usage not measured` warning with the error.

### Fixed

- Measuring a Space with millions of files could hold every build on its server. The measurement walked the volume once a minute, did not finish inside its limit, kept running after Orbit gave up on it and was started again thirty seconds later, until the walks side by side put the disk under enough pressure for Orbit to hold builds. Nothing walks a Space's volume or lists its bucket to measure it any more.
- A measurement that took too long kept running inside the database after Orbit gave up on it. Where the database's image has GNU `timeout`, the walk of its data directory now ends after 10 seconds where it runs. On Alpine images, which are Redis and a PostgreSQL that is not on CloudNativePG, it runs as before.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com

## Validation

Hosted CI could not run: GitHub Actions did not start the full backend run because of account billing. The release was verified locally instead, recorded in the signed `VALIDATION.json`:

- Go tests and vet (56 packages), type checks, 838 TypeScript and 229 console unit tests, the contract, the docs build and the highlights.
- The race detector on Linux. The steps ran side by side, and under that load two tests failed on timing with no data race reported: one in replication and one in the AI machine agent's update. Alone they passed 3 of 3 and 5 of 5.
- 368 of 368 journeys of the installed console and 267 of 267 desktop journeys.
- The smoke test against the built binary, the pinned signature, the checksums, both binaries on amd64 and arm64, and the AI machine agent for macOS and Linux inside them.
- The new measurement of a Space ran, read only, against a real Space with 3.7 million files, and against a Garage 2.4.1 started for the test. The bounded walk ran in the images of PostgreSQL, MongoDB, Neo4j, OpenSearch and Redis.
- Not run before publication: no installation was upgraded to this build first, as earlier releases did with a three server fleet. The wiki's folder access ran against the tests' server and demonstration data only, and MySQL's image was not checked for GNU `timeout`.
