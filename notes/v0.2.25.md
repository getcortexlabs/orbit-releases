The redesigned Orbit console is now included in the public release.

### New

- **Mavis throughout the console.** Login, workspace navigation, projects, servers, activity, databases, settings, the app catalog, email, DNS, Spaces and backups use the new interface. Guided onboarding and update highlights are included.
- **Jolt motion.** Content transitions and interaction feedback respect reduced motion. Navigation stays in place between pages.
- **One public package.** The Mavis client is embedded in the Orbit binary. New installations and updates from Settings receive it without installing Node or a separate console service. Existing hash-based bookmarks continue to open their destination.

### Upgrading

- No new metadata schema migration. Authentication, permissions, operations, event streams and terminals continue through the existing Go API.
- Signed Linux AMD64 and ARM64 packages retain the archive format accepted by earlier Orbit updaters. Existing private beta installations stay on their private channel.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
