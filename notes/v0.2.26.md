Install Ranjit from the app catalog and connect it to your backend.

### New

- **Ranjit in the catalog.** Orbit creates PostgreSQL, generates an API key and configures the service address. Use Ranjit v0.3.0 from your backend with the Go SDK, starting with OFX/CSV statement imports.
- **Installation guidance.** Both consoles explain the required bank API access and credential configuration. The mobile review keeps long variable names and generated keys within the screen.

### Upgrading

- No new metadata schema migration. Existing projects and private beta installations keep their current configuration and channel.
- Bank API credentials and access must be enabled separately. Installing Ranjit does not grant access to bank accounts.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
