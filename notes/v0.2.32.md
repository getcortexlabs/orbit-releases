A more consistent console, with workspace creation available wherever you are.

### Changed

- Refined shared Mavis controls, DNS filters and record forms, settings navigation and search, notification channels and application email. Buttons and selectors keep a consistent scale on desktop and mobile.
- New workspace opens in place from desktop and mobile navigation. Cancelling keeps the current page; confirmed creation selects the workspace and opens its projects. Recoverable errors preserve the draft.
- Updated Mavis to 0.1.0-rc.13 and Jolt to 0.1.0-rc.15. Removed individual scene playback buttons while preserving the decorative animation preference and reduced motion.

### Fixed

- Closing sheets and nested selectors releases their modal backdrop, allowing the page to receive clicks again. Workspace dialogs restore keyboard focus after closing the mobile menu.
- Responsive artwork waits for visible layout and releases animation ownership correctly when resizing or navigating.
- The private Nuxt console proxies setup and terminal connections correctly after the build; unauthenticated requests retain their normal authentication response.

### Upgrading

- No metadata migration or automatic changes to hosted applications or infrastructure configuration. The private beta remains restricted to the existing authorized fleet.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
