Read, organize and reply to Hostinger Email messages from a workspace in Orbit.

### New

- **Workspace inboxes.** Connect a Hostinger Mail API token and use its permitted mailboxes inside Orbit. Browse folders, search messages, download attachments, mark messages as read or starred, archive and move messages, compose and reply. Viewers can read, developers can send and organize, and administrators manage the connection.
- **Protected mail content.** Tokens stay encrypted on the server. HTML messages are sanitized and sandboxed, with remote images blocked. A send is confirmed only after Hostinger accepts it; an uncertain result preserves the draft and is never retried automatically.
- **Motion and layout.** Jolt animates message entrances, reader transitions and send confirmation, while respecting reduced motion. Dialogs have consistent spacing, keyboard focus and layouts for desktop and mobile in both themes.

### Setup and scope

- Open **Email → Connect Hostinger Mail**. Create a Mail API token in your email domain's **Agentic Mail → API access**, restricted to the mailboxes you want to share. The existing Hostinger DNS/VPS token is not accepted directly by the Mail API; automatic provisioning through that connection is not included in this version.
- Each workspace supports one Mail connection with multiple permitted mailboxes. Additional inbox providers, outgoing attachments, persistent drafts and Titan mailboxes are not supported.
- No new metadata schema migration compared with 0.2.23. Existing private beta installations remain on their private channel.
- The same application changes were tested locally and deployed to the three private-beta hosts with healthy controllers, agents and synchronized replicas. Real Hostinger mailbox permissions and delivery still require account-level validation.

Networking and clock preflight checks were unavailable in the offline test container.

GitHub Actions did not execute because GitHub reported an account billing or spending-limit restriction. No successful full hosted CI validation is claimed. The implementation previously passed the full local Go suite and 10 inbox browser journeys; its private beta was deployed and checked on the existing three-host fleet.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.
