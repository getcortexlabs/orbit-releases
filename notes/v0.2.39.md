### Added

- Create private Neo4j Community or OpenSearch instances in a workspace or project. Each instance has persistent storage and application credentials. Use native recovery tools for these engines. Orbit-managed backups, restores and password rotation are unavailable for them in this version.
- Organize the installation, workspace and project wikis with folders. Nest and move pages or folders, browse the library and keep empty folders in Markdown exports.
- Choose personal colors for buttons, links and secondary accents. Colors follow the account across sessions and adjust for readability in light and dark mode.

### Fixed

- Moving between Projects, the app catalog and AI machines keeps loaded content visible. Loading placeholders now follow the background in high-contrast dark mode.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
