### Changed

- Orbit reads a service's internal address over its Kubernetes API connection instead of starting `kubectl`. On the fleet this was nearly every `kubectl` process Orbit still started.
- The certificate issuer and a Space's storage access rules are applied again only when they change, or every five minutes, instead of on every static site pass.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com

- The fleet runs this version. On the leader, Orbit started 0 `kubectl` processes in a minute, down from 250 on 0.2.41 and 60 on 0.2.42.
