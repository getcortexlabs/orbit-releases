### Added

- Builds from a GitHub repository can fetch the private repositories that Orbit's GitHub App can read, including Go modules, Cargo git dependencies and submodules, with nothing to configure. Each build gets its own read-only token, revoked when the build ends, and the token never reaches the image or the logs.
- Serve gRPC applications on their public address. Orbit recognizes gRPC servers and switches the route to HTTP/2 once the port answers it, or you can choose HTTP or gRPC under **Build and start**. Streams are no longer cut after 60 seconds.
- See each application's internal address on its overview, and reference another application's address, host or port from a variable.
- Reserve less memory than an application's limit. The memory suggestion now lowers the reservation from the measured peak, and databases get a size suggestion that keeps each engine's memory settings consistent.
- Orbit flags placeholder text such as `<your-token>` in start commands, build commands and variables before you deploy.

### Changed

- A build starts when its memory is free on the server, instead of waiting for room that application reservations leave. A build that can never fit fails at once with both amounts, and a waiting build says what it needs and what is free. The resources screen no longer shows build headroom.
- Applications in other workspaces can no longer reach an application's pods.
- BuildKit runs only while a build needs it, and Kubernetes keeps memory for the system and evicts a pod gracefully before the kernel stops a process. After the update each server restarts K3s once, and Traefik restarts once to allow long requests.
- Server memory is counted in GiB, so capacity matches what the machine really has.
- The memory lab leaves the console, and the private beta channel is retired.

### Fixed

- When a server runs short of memory during a build, the build is stopped first instead of an application.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
