### Added

- Orbit detects Mavis projects from `mavis.config.json`. Nuxt with server rendering runs as a Node service from the root `build:web` script, Nuxt generated pages and Vue with Vite become static sites with no application container, and the detection says which targets run on devices.
- The documentation has a new design: Orbit's palette and fonts, a home page with a 3D planet and orbits, a self-typing install terminal and a deploy path drawn as you scroll, with motion by Jolt. Nothing moves with reduced motion.

### Changed

- The notification watcher saves how far it has read at most once a minute while the events give nothing to notify, instead of after every batch of log lines.
- An application or database whose state has not changed is written again every five minutes instead of every 30 seconds, and its state reads as stale after six minutes. A change is still written within 15 seconds.
- Every event is written once, with its payload, instead of being inserted empty and updated.
- Uptime checks are counted in memory and written every ten minutes or when the status changes. A restart loses at most ten minutes of counted checks.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
