### Changed

- Static sites are published again only when their route, release or file servers change, or every five minutes, instead of every 15 seconds. On a server with a few sites this removes almost all of Orbit's background `kubectl` processes. A change made by hand to a site's objects is restored within five minutes.
- Orbit runs commands inside containers over the Kubernetes API instead of starting `kubectl`, and deletes, labels, scales and reads several kinds of objects the same way. `ORBIT_KUBE_API=off` in `orbit.service` still sends everything back to `kubectl`.
- Every 15 minutes Orbit logs which commands still started `kubectl`, if any.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
