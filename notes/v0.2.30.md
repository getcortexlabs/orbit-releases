# Orbit 0.2.30

Opening Build in application settings now shows the options instead of failing with an unnamed-sheet error. Choose Dockerfile, Automatic build or Static files and save as usual. The field and options sheet keep their translated names when the language changes.

No metadata migration or automatic changes to existing build settings.

Fix: https://github.com/getcortexlabs/orbit/pull/440

## Validation

Local checks passed: 707 application tests, 183 Mavis tests, both type checks, 18 CI helper tests, seven private installer and rollback tests, production builds and 44 browser scenarios against the Linux release binary. A focused Chromium check exercised the Build selector in Portuguese on desktop and English on mobile. Public and private bundles were checked on AMD64 and ARM64 for signatures, checksums and executable versions; the private Nuxt console served login and assets as an unprivileged user.

The full GitHub Actions run for the release commit could not start because of account billing or spending limits: https://github.com/getcortexlabs/orbit/actions/runs/42449280358. Local validation does not represent successful full hosted CI. The signed VALIDATION.json records this limitation.

The maintainer explicitly approved manual publication and the existing-fleet update with this CI limitation disclosed.
