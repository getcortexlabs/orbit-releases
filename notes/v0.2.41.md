### Changed

- Orbit talks to Kubernetes over one reused connection instead of starting a `kubectl` process for every read, leader check and apply. Reads, leader checks and server-side applies no longer start a process, each of which used up to 200 MiB; exec and a few other commands still do, and the next release moves them too. Set `ORBIT_KUBE_API=off` in `orbit.service` to go back to `kubectl`.
- BuildKit stops when idle on every server that can build, standbys included, and no longer starts at boot.
- Replication keeps its window of recent changes without copying it on every change.

### Fixed

- BuildKit no longer shows as failed after it stops for being idle.
- A build admission test no longer fails at random under the race detector.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
