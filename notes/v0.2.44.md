### Changed

- The active Orbit keeps only the newest 1,024 replication changes in memory instead of all 20,000. A standby that falls further behind reads the rest of the same window from disk. On the fleet leader this held about 150 MiB of live memory.
- Application log positions are written only when they move, instead of rewriting every file's position on each batch of log lines.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
