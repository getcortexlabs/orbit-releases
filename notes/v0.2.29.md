Build within your server's capacity and remove unused connections with a clear preview.

### New

- **Build capacity controls.** Configure CPU, memory, workspace and concurrency budgets on the actual build executor. Excess builds wait in arrival order without blocking operation workers. Deployments show the executor, waiting time, execution time and a concrete capacity reason. CPU throttling and OOM diagnostics use kernel evidence.
- **Safe removal.** Remove disabled receiving configurations and unused backup destinations through a preview and a resumable operation. Disconnecting preserves provider data. Deletion is limited to resources Orbit created and can still verify; shared or adopted resources stay. Referenced destinations and nonempty buckets cannot be deleted.

### Changed

- Server connection and release highlights use refreshed Mavis layouts, clearer choices and responsive dialogs.
- BuildKit processes and containerd build executors share enforced host limits. Existing etcd disk-write protection also covers executors. Cancellation and controller recovery fence the previous attempt before releasing its reservation.

### Upgrading

- No new metadata schema migration. The private beta stays restricted to the existing authorized fleet.
- Build admission requires Linux cgroup v2 and supported host controls. Missing pressure telemetry serializes builds; missing core capacity measurements prevent admission. Review the effective budget on small servers: a reservation that does not fit waits until adjusted.
- Controlled builds use the pinned built-in Dockerfile frontend. External `# syntax` frontends are not loaded. Workspace is an admission estimate rather than a filesystem quota; Git checkout and static packaging remain outside the BuildKit cgroup.
- Legacy receiving and storage resources without verified creation ownership are preserved. This release does not automatically remove retained test resources or production data.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
