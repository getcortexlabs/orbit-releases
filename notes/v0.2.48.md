0.2.47 was not published: validating it on the fleet showed the client address problem fixed below, and its changes ship in this release.

### Added

- Network exits: a computer of the workspace, such as a Mac, an Orange Pi or a mini PC, carries chosen outbound connections of applications through its own internet, so destinations see its address instead of the server's. One command pairs it on macOS or on Linux (ARM or x86, as a hardened systemd service under its own unprivileged user); its agent dials Orbit, opens no port, idles at about 8 MB on Linux and updates itself with Orbit. A grant lets a project's applications leave through chosen devices to listed destinations only, with exact names, addresses or a leading wildcard, and an application gets its own proxy address through a reference in Variables. Destinations outside the grant get 403 and, with no device online, applications get 503: nothing ever leaves through the server's address. The device refuses its own network.
- The Network exits page lists devices with their status, open connections and traffic of the last hour, tests an exit by showing the address the destination saw, pauses, resumes, revokes and removes devices, and manages grants. A step by step guide takes anyone to a first working exit, recommends hardware and what to ask for at the store, and saves the plan so it resumes on any browser.
- Open and download Space objects with the console session, browse image thumbnails and file types, and configure an existing CDN address for shareable links.
- Insert images in wiki Markdown by URL or upload, and move folders with their contents and history between General, workspace and project collections.

### Changed

- The console uses Mavis RC.16 and Jolt RC.18. Clear searches in place in the overview, Spaces and wiki. Space images open in a keyboard-accessible viewer with zoom and navigation. Appearance changes now update both palettes together.
- Space inventories and detail pages bring files and delivery settings forward. The overview search fits its toolbar and server illustrations stay in place on hover.
- BuildKit now bounds its build cache to a tenth of the disk. A recovered worker can pass admission after its initial restart.

### Fixed

- Orbit, applications and network exit tests see the real client address. On servers whose node address is private or on the overlay, as on every server of a fleet, requests reached Traefik through K3s's ServiceLB, which replaced the client's address with its own (10.42.x.x in X-Forwarded-For). Traefik now listens on the servers' ports 80 and 443 itself and its Service only serves the cluster; existing installs switch once at startup, which restarts Traefik and interrupts each entry server for a few seconds. A network exit test that still reaches Orbit from a private address says the address is hidden instead of showing it.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
