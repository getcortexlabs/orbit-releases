### Added

- AI agents through the Model Context Protocol. Orbit serves MCP itself at `/api/v1/mcp`, so Claude, ChatGPT, Claude Code, Cursor, VS Code and other clients can read the workspace's projects, applications, logs, metrics, deployments, incidents, backups and wiki, and write wiki pages. Every tool calls the same API operations as the console, under the same roles, and answers are bounded. Logs, pages and build output are marked as text to read, never as instructions.
- Agents sign in as you. Orbit is the OAuth server of its own MCP endpoint (authorization code with PKCE, dynamic client registration and the standard metadata), so a Claude.ai or ChatGPT custom connector only needs the address. A consent page shows the account and where the agent returns, and lets you choose the workspaces and the most it may do; it never acts above your own role. Agents work in one workspace at a time and switch with `list_workspaces` and `use_workspace`. What they change is recorded under your name with the agent beside it.
- Agents deploy, roll back, back up databases and test restores, as developers. Every action takes two calls: the first only answers a summary of what will happen and a code, and the second runs it with that code, which works once, for two minutes, for exactly the same arguments. `get_operation` follows the result.
- Settings > Security: Connect an AI agent writes the setup for each client with the token you just created, and Connected AI agents lists the agents acting as you, where they work and when they were last used, and disconnects them at once.
- `orbit-mcp`, a small bridge for clients that only start local programs, such as Claude Desktop. Each release publishes it for macOS, Windows and Linux, listed in the signed checksums.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
