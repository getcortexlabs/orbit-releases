### Added

- Data explorers for Neo4j and OpenSearch, read only. Neo4j shows a bounded sample of the graph, finds nodes by label or text, opens a node's neighborhood and its properties, and draws relationships as curved arrows that keep parallel and reciprocal ones apart. OpenSearch picks an index, searches by relevance, pages 25 documents at a time and shows each one's fields and its exact JSON, ready to copy. Requests go through a fixed path inside the cluster, never expose credentials and are bounded in size and time.
- The wiki's Workspace architecture template. In a workspace or project collection, Orbit reads the projects, applications, databases, Spaces, domains, servers and the variables that reference another service, and opens a page with a diagram of how they connect, a section per environment whose names show their status live, and the servers that receive traffic. Pull request previews stay out of the diagram, and using the template again redraws the page while its history keeps the previous version.
- Wiki pages draw diagrams written in a `mermaid` code block, in the colors of the current theme.

### Changed

- The PostgreSQL, MySQL, MongoDB and Redis explorers share a redesigned studio: the first table or key opens by itself, lists move with the keyboard, the query workspace and its results read better, Redis strings show as JSON or as their original text, and a recoverable error keeps the results on screen. A late reply can no longer replace a newer selection.
- The AI agents guide explains that the `orbit-mcp` bridge is not signed by Apple or Microsoft, how a browser download is unblocked, and how to check it against the signed checksums.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
