Collect form submissions and review them by email, keep subscribers informed about incidents, receive email in your applications, and protect backups and preview data.

### New

- **Shared email and forms.** Applications can use Orbit to send email with their own HTML or a Resend template, collect submissions and publish approved entries. Review links open a confirmation before approving or rejecting, so an email scanner cannot make the decision. Choose the sender's display name.
- **Status-page subscriptions.** Visitors confirm their email address before receiving incident and recovery updates. Unsubscribe takes effect after confirmation and stops later notifications.
- **Incoming email for applications.** Set up a receiving subdomain, fetch the message body and attachments, and deliver them to an application with a signature it can verify. Failed deliveries retry; addresses can also forward to a mailbox. Authenticated replies to Orbit alerts are implemented, with the real mailbox acceptance still pending as noted below.
- **Private R2 backup destinations.** Orbit creates the bucket and credentials restricted to it through your Cloudflare connection, checks access and waits for a newly created key to become usable. Keep database and Space backups away from the server they protect and verify them with isolated restore tests.
- **PostgreSQL data for protected previews.** Prepare an isolated copy from a verified backup, mask sensitive data and remove sessions before exposing the preview. Access checks use the current Orbit session and workspace membership, including after access is revoked.
- **Static headers and redirects.** Store per-site rules with each immutable release so publishing and rolling back keep the site's files and routing rules together.
- **Guided build fixes.** Recognized build failures offer a configuration change to review from the console before trying again.

### Fixed

- Email review confirmation works from the browser instead of returning 403.
- Hostinger TXT records retain a stable ID when the provider returns quoted values, so a record can be updated or deleted using the ID from creation.
- Protected static deployments verify the published route without requiring anonymous access to a private page. Configured root redirects no longer make a valid deployment fail its check.
- Inbound attachment downloads accept the provider's real HTTPS URLs while rejecting private destinations, redirects and credential forwarding. Pending receiving domains refresh automatically, and early webhook events remain retryable.
- Local MySQL operations use TCP, avoiding an unintended socket connection.
- Backup, availability and email journeys have clearer layouts and actions.

### Upgrading and validation

- No new metadata schema migration since 0.2.21. Email, forms, subscriptions, receiving addresses and new backup destinations need explicit configuration.
- This release uses local validation as requested by the maintainer; it has no successful full hosted CI attestation. Backend, API, security/race, frontend and browser checks covered the changed areas. Real K3s/Traefik and PostgreSQL checks covered preview access, masking, isolation and rollback. Real-provider checks covered status email and unsubscribe, signed inbound delivery with an attachment and retry, DNS record operations, and external backup/restore.
- Real authenticated replies to Orbit alerts remain an acceptance follow-up: the test reply did not appear in Resend Receiving, so the end-to-end action has not been verified. A paid Hostinger VPS order and a fresh Resend webhook creation response were also deferred.
- Removing a disabled receiving configuration or an unused backup destination is not yet a complete managed flow. Preserve referenced provider resources until that lifecycle is supported.
- Installations on the private beta stay on that channel. The corresponding private 0.2.23-beta.1 includes these 0.2.22 highlights in the console.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.
