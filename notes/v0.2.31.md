A more spacious project workspace, with clearer controls from deployment to debugging.

### Changed

- Redesigned deployments, metrics, terminal, domains, variables, Kubernetes and settings with Mavis layouts and Jolt content transitions. Desktop panels use the available width; mobile layouts remain comfortable.
- Deployment details place stages beside logs, with a readable search field. Metrics distinguish missing telemetry from errors and offer a retry. Variable edits preserve drafts after a failed save.
- Project navigation stays in place when switching tabs. Kubernetes details close cleanly and return keyboard focus to their trigger. English, Portuguese, light and dark themes and reduced motion are covered.
- The app catalog now pins Ranjit to v0.4.0 for new installations. Existing installations are not upgraded automatically.

### Upgrading

- No metadata migration or automatic changes to projects, domains, variables or infrastructure configuration.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
