### Added

- Administrators can try a model from an AI machine's page. The prompt goes through the same relay applications use, the answer streams in, and the page shows the time to the first token, tokens per second, which machine answered and whether the model had to load. Models that see images take one image. Nothing is stored.
- The agent on an AI machine updates itself to the version Orbit carries. It downloads and checks the new agent while it keeps serving calls, waits for the calls in flight, replaces itself and starts again through launchd. Agents installed before 0.2.46 need the connection command once.

### Changed

- A server with no saved build policy lets a build use half of its CPU cores, never fewer than two. A build slowed by the CPU limit says the limit and where to change it.
- The repository list on the new project page shows each repository's name with the lock on the right, and the branch is chosen from the repository's branches.

### Fixed

- Clickable cards that had lost their styles came back: activity entries, the new project and add server cards, the server source and access method choices, and backup cards on phones. On phones the server source cards could not be chosen from the keyboard.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
