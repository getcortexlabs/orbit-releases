A clearer, redesigned home for Orbit updates.

### Changed

- **Updates with Mavis and Jolt.** The updates screen now highlights the available version, with Ted, separate cards for the installed version, metadata backup and environment checks, and release notes grouped by type. Package details and migrations are expandable.
- **A clearer update review.** The confirmation shows the update plan step by step, keeps recovery commands visible and still requires you to save them before installation. English and Portuguese are included.

### Fixed

- The console hostname form and settings search stay within the page on desktop and mobile.
- A failed status request shows an explanation and a retry action instead of leaving the screen blank.
- A metadata backup is only described as verified when the server confirms it.
- Unsigned releases, stale or blocking checks, and duplicate submissions cannot start an update from the console.

### Upgrading

- No new metadata schema migration. Existing projects, permissions and private beta channels retain their current configuration.
- Check for the new public version in **Settings → System → Orbit updates**, or use the installer below.

## Install or update

On a server with Ubuntu 22.04, 24.04 or 26.04, or Debian 12, on x86_64 or arm64:

```sh
curl -fsSL https://github.com/getcortexlabs/orbit-releases/releases/latest/download/install.sh | sudo sh
```

Servers on 0.1.22 or later can also update from Orbit updates in Settings.

Documentation: https://orbit.getcortexlabs.com
